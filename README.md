# Cage Rush

Arcade MMA fighting game in a single file: `index.html`. Open it in a browser to play. Works on PC and mobile.

## Working on it together
1. Pull before you start: `git pull`
2. Make your change, open `index.html` in a browser to test
3. Commit and push: `git add . && git commit -m "what you changed" && git push`

Tip: the whole game is one file, so two people editing at once will conflict. Say who is working on what, and work on a branch for bigger changes, then open a pull request.

## Ground rules for the game
- Arcade, fast and fun. Keep the damage numbers and "N HIT" popups.
- Must work on PC and mobile.
- Our own art, no emojis in the UI, no em dashes in game text.
- 2D at its core. 3D is an optional beta setting, off by default.
- Career should be challenging.
